title: FAQ
description: Common questions about fz-maximize.
---

## Do I need PowerToys?

Yes. fz-maximize uses the zones you set up in FancyZones; it doesn't have its own layout
editor. It works alongside FancyZones rather than replacing it: FancyZones still handles
Shift-dragging windows into zones, and fz-maximize handles maximize.

## Does it need administrator rights?

No. It installs and runs under your own account. The flip side is that Windows doesn't let
it move windows of apps running as administrator, so those keep the normal maximize.

## How does it catch maximize before Windows does?

It uses Windows' standard low-level mouse and keyboard hooks, on a thread of its own, to
recognize a click on a maximize button, a title-bar double-click and
<kbd>Win</kbd>+<kbd>Up</kbd>. It doesn't inject code into other apps, record what you type or
click, or send anything anywhere. Everything else it learns from Windows' window events.

## Does it send any data?

No. fz-maximize has no telemetry. Its only network use is the optional update check,
which is off unless you turn it on: once a day it asks GitHub whether there's a newer
release. See [Privacy](/fz-maximize/privacy/#update-checks).

## Does it slow anything down?

It uses about 10 MB of memory and no CPU while idle. It only does work when a window is
maximized, moved or snapped.

## Does it work with several monitors and virtual desktops?

Yes. Each monitor and virtual desktop uses its own FancyZones layout, and docking,
undocking and resolution changes are picked up automatically.

## Does it run on Windows on ARM?

Yes. There are native ARM64 builds; take the `arm64` installer or zip.

## Which version do I have?

Right-click the tray icon and choose **About fz-maximize**. It shows the version, whether
it's the x64 or ARM64 build and how it's installed, and what's new in that version.
Hovering over the tray icon shows the version too. Every version's changes are in the
[changelog](https://github.com/fz-maximize/fz-maximize/blob/main/CHANGELOG.md).

## How do I update it?

Turn on **Check for updates once a day** (Settings → General; fz-maximize also asks the
first time it starts). When a new version comes out, a notification offers it: install it
now, at a time you pick (3:00 AM by default), be reminded in 1, 3 or 7 days, or skip that
version. The update window shows what's new in it first. **Check for updates now** in the
tray menu, or the button in **About fz-maximize**, checks right away; from About you can
install a new version straight away.

You can also update by hand: run the new installer, or `winget upgrade fz-maximize` once
the winget listing is published. Either way your settings are kept, and the running copy
is closed and restarted for you. Releases are announced on the
[GitHub releases page](https://github.com/fz-maximize/fz-maximize/releases).

Updates are downloaded only from this project's GitHub releases, and each file is checked
against the release's published SHA-256 checksums before it's used. A portable copy
updates by swapping in the new `fz-maximize.exe` from the release's zip.

## Why does Windows warn about the installer?

The installer isn't code-signed yet, so SmartScreen doesn't recognize it. Choose **More
info → Run anyway**. Each release lists SHA-256 checksums so you can verify the download,
and the builds are made by GitHub Actions from the public source, with a build-provenance
attestation.

## Is this a Microsoft product?

No. fz-maximize is an independent open-source project, not affiliated with or endorsed by
Microsoft. It's MIT licensed, and parts of it are ported from PowerToys, which is also MIT
licensed.

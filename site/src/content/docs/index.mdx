## Why

On an ultrawide monitor, maximize is rarely what you want: a window stretched across the
whole screen is hard to read and hides everything else. FancyZones fixes window *placement*, but the maximize button,
<kbd>Win</kbd>+<kbd>Up</kbd> and every app's habit of maximizing itself still go full screen.
fz-maximize teaches maximize about your zones.

<CardGrid>
	<Card title="Every way to maximize" icon="rocket">
		The maximize button, a title-bar double-click, <kbd>Win</kbd>+<kbd>Up</kbd> and dragging
		to the top edge all fill the zone the window is in. Maximize again to put it back.
	</Card>
	<Card title="Full screen when you want it" icon="seti:windows">
		Hold <kbd>Shift</kbd> while maximizing, or press <kbd>Win</kbd>+<kbd>Shift</kbd>+<kbd>Up</kbd>,
		for a normal full-monitor maximize. The key is your choice.
	</Card>
	<Card title="Feels like Windows" icon="star">
		No flash of a full-screen window first. The move into the zone is animated in the style of
		your Windows version, at Windows' own speed, and zone-maximized windows lock like truly
		maximized ones.
	</Card>
	<Card title="Your FancyZones layouts" icon="puzzle">
		Reads layouts straight from FancyZones: templates, custom grid and canvas layouts, per
		monitor and per virtual desktop. Change a layout and the next maximize uses it.
	</Card>
	<Card title="Light and private" icon="approve-check">
		A small native app: about 10 MB of memory, no CPU while idle, no admin rights, no
		DLL injection, no network access, no telemetry.
	</Card>
	<Card title="Open source" icon="github">
		MIT licensed, built in Rust. Native builds for x64 and ARM64 Windows.
	</Card>
</CardGrid>

## Install

fz-maximize needs Windows 10 or 11 and [PowerToys](https://learn.microsoft.com/windows/powertoys/)
with FancyZones turned on.

<Tabs>
	<TabItem label="Installer">
		Download `fz-maximize-<version>-x64-setup.exe` (or `-arm64-setup.exe` for Windows on ARM)
		from the [latest release](https://github.com/fz-maximize/fz-maximize/releases/latest) and
		run it. It installs for your account only, with no admin prompt.
	</TabItem>
	<TabItem label="winget">
		```powershell
		winget install fz-maximize
		```
		The winget listing is being reviewed; until it's published, use the installer.
	</TabItem>
	<TabItem label="Portable">
		Download `fz-maximize-<version>-x64-portable.zip` from the
		[latest release](https://github.com/fz-maximize/fz-maximize/releases/latest), extract it
		anywhere and run `fz-maximize.exe`.
	</TabItem>
</Tabs>

Then see [Getting started](/fz-maximize/getting-started/).

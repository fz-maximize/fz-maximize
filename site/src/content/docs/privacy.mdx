---
title: Privacy
description: What fz-maximize stores, what it sends (only an optional update check), and what it doesn't collect.
---

**fz-maximize doesn't collect or share any data about you.** It contains no telemetry,
analytics or crash reporting. Its only network use is the optional
[update check](#update-checks), which is off unless you turn it on.

## What it reads

To do its job, fz-maximize reads, on your computer only:

- FancyZones' layout and settings files, in `%LOCALAPPDATA%\Microsoft\PowerToys`;
- the position, size, title and app name of windows as they are maximized, moved or
  snapped;
- mouse clicks and the <kbd>Win</kbd>+<kbd>Up</kbd> key combination, only to recognize a
  maximize before Windows acts on it. Nothing you type is recorded;
- your monitors' identities (model and serial number, from Windows), to match them with
  FancyZones' layouts.

## What it stores

All on your computer:

| What | Where |
|---|---|
| Your settings | `%APPDATA%\fz-maximize\config.toml` |
| A log of what it did, including the app names (like `notepad.exe`) of windows it moved | `%LOCALAPPDATA%\fz-maximize\fz-maximize.log` |
| Monitor identities it has seen, for when Windows can't report them | `%LOCALAPPDATA%\fz-maximize\monitors.json` |
| Update check state: when it last checked, and versions you skipped, scheduled or asked to be reminded about | `%LOCALAPPDATA%\fz-maximize\update.json` |

Uninstalling keeps these files in case you reinstall; delete both folders to remove them.

## Update checks

**Off unless you turn it on.** The first time fz-maximize starts, it asks whether to check
for updates; you can change your answer any time in **Settings → General**.

When it's on, once a day fz-maximize asks GitHub for this project's latest release: an
HTTPS request to `api.github.com/repos/fz-maximize/fz-maximize/releases/latest`. Choosing
**Check for updates now** in the tray menu makes the same request, whether or not daily
checks are on.

- **What's sent:** an ordinary web request. GitHub sees your IP address, as with any web
  request, and the request names the app and its version (`fz-maximize/0.3.5`). Nothing
  else: no identifier, no information about your PC, your windows or your settings.
- **When you install an update:** fz-maximize downloads the release's files from
  `github.com/fz-maximize/fz-maximize/releases`, the same files as the Download links.
- Requests go through Windows' own networking, so your proxy settings apply.

GitHub's
[privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)
covers these requests.

## Downloads

Release files are hosted on GitHub, and this site on GitHub Pages; GitHub's privacy
statement covers those downloads and visits. If you install with winget, Microsoft's
winget service is involved in finding the download.

## Changes

Any change to what fz-maximize sends will be described here and in its release notes.

Questions: [open an issue](https://github.com/fz-maximize/fz-maximize/issues).
